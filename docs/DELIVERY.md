# NaturalStreaming 后端开发交付记录

日期：2026 年 11 月 18 日。需求内容修订 1.1，接口契约 1.0。

- 草稿上传、实际媒体解码、哈希及配置校验、修订冲突控制、显式发布、下架和回滚。

- 开发服务器独立部署、六域名 HTTPS、证书续期 timer、版本化升级及回滚辅助脚本。

- 真实公网与 MySQL 回归 11 组通过，含权限隔离、坏哈希、空参数、草稿锁定、发布不可变、修订冲突、校验失效、媒体声明、重叠上限、Range/HEAD、设备撤销、并发登录、下架/撤权及账号禁用。
- 数据库事务交错测试 2 项通过：校验等待锁后读取当前内容；发布等待锁后拒绝未验证新修订。此前旧实现已被该测试复现失败，修复后通过。

- 无关项目 Nginx 配置哈希未变；已有 AiChef/SayTavi/CRM 等应用 MainPID 未变且服务 active。未修改其他项目代码、数据库、基础目录权限或 SSH。

构建存在 Maven/Guice 在 JDK26 上的 Unsafe/反射弃用警告，以及部分 Java 泛型转换警告；没有编译错误或测试失败。

## 审查修复

独立只读审查发现并修复：MySQL REPEATABLE READ 校验/发布旧快照、过宽媒体格式与协议解析、声明时长/采样率不核对、上传链接和 ZIP 边界、服务凭证身份比较、过长重叠导致超出双片段预算、共享临时部署脚本与并发切换。重复 scope 已规范化并覆盖真实接口测试。

媒体时长使用解码样本时间，允许与容器/清单声明相差 0.15 秒；重叠上限为每片段时长一半。前端输出保护具体参数在 PLAYBACK.md，防止实现方各自猜测。

## 尚需内容与前端验收

真实“森林的早晨”“柔软的钢琴”仍为草稿：原包轨道是占位名且来源授权未声明已审核。需内容人员完成试听名称、description、授权审核后由发布者显式发布。后端未编造声源身份或授权。

另有 `integration-tone-demo` 十轨 CC0 合成信号，明确显示“联调测试音（非音乐）”，供测试账号立即接线，不替代真实音乐与听感验收。

Android App、断网实际播放、锁屏与音频焦点、十轨混音听感及性能由前端按规格书验收。后台网页、地图、电台和 AI/语音均不在首版范围。

## 私有接入资料

前端：本机 `.local/frontend-access.json`，含上传 scope 与测试账号，无发布权限。后端负责人：`.local/owner-access.json`。两者都不进 Git，不在本文写 token/password。前端同机可直接读取，异机需负责人私下传递。
