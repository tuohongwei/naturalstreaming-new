状态：首版需求已确认，补充决策见第 13 节

## 1 产品目标与首版边界

NaturalStreaming 是一款由本地音频播放器执行多轨混音的背景声音 App。后端保存主题包，App 先同步索引，再根据用户选择下载缺少的音频，在本地完成播放。

首个联调链路为：同步索引 → 手动选择主题、轨道和预设 → 只下载缺失片段 → 校验 → 本地播放 → 断网后再次播放。

### 1.1 已确认纳入首版

- 独立账号体系及测试账号主题授权。
- 已发布主题目录、封面、简介和轨道说明。
- 单个主题内选轨，应用现有预设，逐轨调整音量和静音。
- 按需下载、按哈希复用缓存，以及主动下载整个主题。
- 本地 A/B 循环混音、暂停、恢复和定时停止。
- 已准备配置的离线播放。
- 独立后台 API，草稿上传、校验和具备权限账号的显式发布。
- 固定主题版本、文件清单及鉴权下载地址。

### 1.2 后续阶段

- 地图和电台模式。
- 跨主题选轨与组合。
- AI 描述生成、语音控制和语音注册。
- 收费订阅、支付和离线 DRM 均未纳入首版范围。

初期接入语音注册的早期设想已由当前手动播放范围替代。后续语音流程参考 SayTavi，首版启动和播放不依赖语音登记。

## 4 主题包与数据模型

### 4.1 导入结构

兼容已提供附件中的结构：

```text
themes/<theme-id>/
  scene.json
  manifest.json
  media/
    1a.wav
    1b.wav
    2a.m4a
    2b.m4a
    ...
    cover.jpg
```

- `scene.json` 描述逻辑轨道、片段顺序、增益、重叠时间、预设及已有空间字段。
- `manifest.json` 描述分发文件、大小、SHA-256、编码、声道及来源追溯。
- `media/` 保存实际分发文件。
- 兼容现有 `schema_version: 1` 和字符串轨道 ID，不任意更名或改变既有字段含义。
- `schema_version` 表示格式版本，另设内容版本标识某次固定发布。
- 首版保留空间字段，但不启用地图交互或据此宣称已实现空间音频。
- `source_path` 为来源追溯字段，不要求原始 OGG 必须随移动分发包存在。
- 导入忽略 `.DS_Store`、`__MACOSX` 等系统附带文件，不将其作为媒体发布。

### 4.2 核心实体

| 实体 | 主要内容 |
|---|---|
| 账号和会话 | 登录凭证、会话有效期、撤销状态 |
| 主题授权 | 哪个账号可查看和下载哪个主题 |
| 主题 | 稳定 ID、名称、简介、封面、当前发布版本 |
| 主题版本 | 内容版本、固定配置、文件引用、状态、创建及发布时间 |
| 主题轨道 | 主题版本、轨道 ID、名称、描述、有序片段及播放参数 |
| 媒体文件 | 内容哈希、存储键、实际格式、采样率、声道、时长和大小 |
| 上传凭证 | 身份、权限范围、有效状态和撤销信息 |
| 校验与发布记录 | 版本、结果、字段级问题、操作主体和时间 |

主题轨道与实际文件分离，同哈希媒体可以复用。首版直接支持完整主题导入，不强制先建设标准素材库和音乐风格编辑系统；独立素材库作为后续扩展。

### 4.3 首发素材

附件实际包含“森林的早晨”和“柔软的钢琴”，每个主题均为 10 条轨、20 个音频和 1 张封面，带 5 个预设。根 README 中提到的“海岸的家”不在本附件中。

两个包属于空间音频验证样例，当前轨道名称和点位含占位内容。首个联调采用“森林的早晨”，内容人员负责试听标注。正式内容发布前补齐可辨认的轨道名称、简短描述及来源授权。

## 5 用户操作与播放规则

### 5.1 主流程

1. 在线登录，获取主题目录和授权。
2. 选择一个已发布主题及固定版本。
3. 选择轨道，应用预设或手动设置各轨音量、静音。
4. App 准备缺失文件并显示下载、校验或失败状态。
5. 全部必需文件就绪后开始播放。
6. 播放中调整预设、音量、静音，或暂停、恢复、设置定时停止。

### 5.2 A/B 循环

- A/B 是同一逻辑声源的两个有序片段，播放顺序 A → B → A，持续循环。
- 每轨独立推进，再按各轨增益混合输出。
- 根据 `overlap_seconds` 提前启动下一片段。
- 重叠区直接叠加，不额外引入交叉淡化包络。
- 切换预设不重启片段、不重置当前播放位置。

### 5.3 预设

支持现有均衡、轻声、前半组突出、后半组突出、缓慢变化五组预设。

- 预设切换使用 2 秒平滑过渡，现有包的 `transition_seconds` 均为 2。
- 未来导入其他值时应明确校验策略，不静默改变配置含义。
- 缓慢变化按照配置周期更新目标并平滑变化。样例为 30 秒目标更新间隔、基准增益的 0.75～1.15 倍范围。
- 零增益及静音轨保持无声。
- 前端需统一动态目标选择和平滑实现，不能把 30 秒解释为一次突变。

### 5.4 控制细则

以下控制细则已确认：

- 选轨决定配置包含哪些轨及必需文件，静音只控制已选轨是否发声。
- 静音和增益分别保存；取消静音恢复保存的增益。
- 切换预设更新已选轨增益，保留用户手动静音，不自动加入未选轨。
- 已选轨即使静音，也提前准备其 A/B 文件，以便立即取消静音。
- 手动修改某轨增益后停止该轨动态变化，再次应用预设时按预设恢复。
- 新增轨道缺文件时先下载准备，原场景继续播放；就绪后再加入。

### 5.5 配置保存与主题切换

- 自动保存当前账号的主题版本、所选轨道、预设、手动音量和静音状态，配置按账号隔离。
- 重开 App 恢复配置，但不自动播放，由用户点击开始。
- 进程结束后不恢复精确片段位置；下次开始从各轨 A 段起播。
- 切换主题时，下载和校验新主题期间继续播放旧主题；准备成功后停止旧主题并启动新主题，不跨主题混播。
- 新主题准备失败时保留旧主题播放及配置，允许重试。

### 5.6 暂停与定时停止

两者由本地实现，不依赖服务器。普通暂停冻结播放进度，恢复时继续；定时停止触发后不自动重播，倒计时归零并重置播放进度，下次手动播放从各轨 A 段开始。

定时器按实际时间倒计时，暂停不冻结计时。切后台或锁屏继续播放，提供系统媒体通知和暂停入口。来电、其他媒体抢占音频焦点或耳机拔出时暂停，不自动切为扬声器播放。中断结束后统一由用户手动恢复，不自动恢复发声。

## 6 索引同步与本地下载

### 6.1 目录同步

- 首次下载授权范围内已发布内容的元数据快照，不自动下载音频。
- 后续使用游标获取新增、更新及下架记录。
- 本地同一事务内保存目录变更和新游标。
- 游标失效时重新获取快照。
- 目录更新不得打断当前固定版本的播放。
- 下架内容从可选目录移除，已激活本地场景保留固定文件引用。
- 普通主题下架不等于撤销账号主题授权，已下载的配置仍可离线使用。明确撤销账号的主题权限时，客户端获知后停止该主题并禁止再次打开；离线设备无法即时获知撤权。
- 索引同步必须区分普通下架和账号授权撤销，不能把两者都当作相同的删除记录处理。

### 6.2 文件准备

1. 固定版本并枚举所选轨全部 A/B 文件。
2. 按 SHA-256 查找已校验缓存。
3. 对缺失或损坏文件批量申请下载地址。
4. 合并同哈希并发请求，支持中断后的断点续传。
5. 下载至临时文件，检查大小和 SHA-256。
6. 校验成功后原子放入可用缓存。
7. 把配置中的媒体引用解析为本地沙盒路径。
8. 所有必需文件可读后才交给播放器。

下载 URL 只供下载模块使用，不传入播放引擎。后端存完整主题版本，客户端不必下载完整归档才能播放。

### 6.3 整主题与离线

- 用户可主动下载该版本全部轨道和封面，复用同一下载校验流程。
- 界面区分“当前配置已就绪”和“整个主题已下载”。
- 配置与必需文件存在时，可断网重新打开并播放。
- 文件缺失或损坏时明确提示，不声称已完整离线可用。
- 新场景准备失败保持原场景，允许重试。
- 首版缓存只提供主动清理；不能清理正在播放使用的文件。

### 6.4 版本更新

已发布版本不可修改，新版本不自动替换当前播放或保存配置；用户主动更新，准备成功后再切换。回滚切换发布指针，不改写历史版本。

历史版本保留与清理周期在实施方案中定义，不能删除仍承诺提供下载的版本文件。

## 7 上传 校验与发布

### 7.1 独立身份与权限

- 上传端 Codex 使用独立服务凭证上传音频和 JSON、创建草稿、触发校验并查询结果。
- 上传凭证默认没有发布权限。
- 校验通过后，由具备发布权限的账号显式发布。
- 普通 App 账号不得调用后台写接口。
- 凭证不得写入 App、主题包、公开文档或代码仓库。

### 7.2 校验内容

- JSON 可解析，格式版本受支持。
- ID 唯一，预设引用及默认预设有效。
- 文件存在，路径相对于包根目录，不允许越界或通过链接访问其他目录。
- A/B 配对和顺序完整，重叠时间小于相关片段时长。
- 实际解码格式、声道、时长与声明匹配。
- 大小和 SHA-256 匹配。
- 增益、坐标和时间均为合法有限值，具体数值范围在 API 契约中规定。
- 轨道名称、描述和来源授权字段齐备。
- 重复上传、重试或发布中断不得产生重复发布或破坏旧版本。

问题结果至少包含错误码、文件或轨道标识、字段位置和可理解的说明。

### 7.3 发布原子性

文件和配置全部写入并验证成功后，才更新当前版本指针。失败时保留旧版本，草稿可以修正后重试。发布和回滚需记录操作主体与结果。

## 8 账号与授权

- 与 SayTavi 独立，可复用账号实现。
- 目录查询、版本读取、下载地址发放均校验账号授权。
- 测试账号只获得指定主题，不默认开放全部主题。
- 下载地址短期有效，并绑定服务端核准的文件范围。
- 下载请求本身也校验当前账号和有效设备会话，不能仅凭尚未到期的地址放行。新设备登录撤销旧会话后，旧地址不能继续发起新的下载请求或断点续传请求；此规则不承诺收回已下载字节。
- 首版不对已下载文件实施离线到期控制；因此撤销权限后无法保证删除设备现有副本，只能拒绝后续在线访问和下载。
- 后台创建用户名密码测试账号，不提供自助注册或短信流程。
- 同一账号实行单设备互斥。另一设备成功登录后成为当前有效设备，旧设备的登录会话失效；旧凭证不能再访问受保护接口或申请下载地址。
- 后端原子完成设备切换及旧会话撤销，并发登录后只能有一个有效设备。旧设备收到明确的会话撤销结果后停止播放并退出当前账号，提示在其他设备登录。
- App 启动和恢复联网时校验会话；在线播放期间每 60 秒检查一次，包括锁屏或后台播放。网络超时和暂时不可达不视为撤销，只有服务端明确返回会话撤销状态才执行被踢退出。
- 普通会话到期时仍可访问本账号已准备的离线内容；不能把已知设备撤销当作普通到期继续使用。退出或切账号后停止原账号播放并隐藏其配置，底层缓存可复用，但新账号在线使用仍需获得相应授权。
- 单设备互斥约束服务端有效登录和在线访问。已离线旧设备无法立即获知另一设备登录；首版保留离线播放，不承诺远程即时停止该设备的本地音频。恢复联网并确认会话撤销后执行退出，不通过新增强制联网或离线到期策略改变此边界。
- 会话校验应同时允许客户端发现已准备主题的授权撤销，不能只依赖可选目录中条目消失推断撤权。普通下架和主题撤权的区别按第 6.1 节执行。

## 10 媒体兼容与运行要求

- 当前样例主要使用 AAC-LC M4A 和 PCM16 WAV。
- 按实际探测结果入库，不只按扩展名判断编码。
- 原始文件与转码产物分别记录哈希和来源关系，不在导入时未经规则静默转码。
- 素材格式支持、A/B 接缝、实际响度和长时间混音需 Android 真机验证。
- 文件哈希通过不代表解码、听感或空间效果通过。
- 对 10 条轨同时播放及重叠时段记录内存、CPU、稳定性及削波情况；硬性性能阈值结合目标测试机确定。
- 播放器必须明确手动增益上限及最终输出防削波策略，覆盖十轨同时输出和 A/B 重叠叠加。具体增益范围、滑块映射和输出保护参数由前后端播放契约统一，并以合法配置校验和真机测试落实，不在本文中假定参数已确定。
- 防削波策略不能将已确认的 A/B 重叠区直接叠加改成片段交叉淡化；保护作用于混合输出的具体方式在播放契约中说明。
- 不修改其他项目或账号的权限、服务和数据来完成部署。

## 13 已确认补充决策

用户确认单设备互斥，并同意其余默认方案。以下为首版决策，不再作为待确认项。

| 事项 | 决策范围 | 已确认规则 |
|---|---|---|
| 平台 | 首版是否包含 iOS | 只做 Android，后端保留跨端兼容 |
| 管理网页 | 是否需要可视化后台，谁负责 | 首版交付后台 API 和上传工具，网页后续做 |
| 账号开通 | 自助注册或后台发测试账号 | 后台创建用户名密码，无自助注册和短信流程 |
| 设备策略 | 同时登录规则 | 单设备互斥，新设备成功登录撤销旧设备会话；离线边界见第 8 节 |
| 后台与锁屏 | 切后台、熄屏是否继续播放 | 继续播放，提供系统媒体通知和暂停入口 |
| 音频焦点 | 来电、其他媒体、耳机拔出后的行为 | 来电或其他应用抢占时暂停，耳机拔出时暂停，不自动外放，中断结束后由用户手动恢复 |
| 定时器 | 暂停后是否继续计时 | 按实际时间倒计时，暂停不冻结计时 |
| 控制细则 | 选轨、静音、预设和动态变化的交互 | 按第 5.4 节执行 |
| 离线身份 | 登录过期、退出、切账号后的本地访问 | 到期可继续本账号已准备内容；退出或切账号隐藏旧账号配置，缓存可复用但不能绕过新账号在线授权 |
| 首发内容 | 主题选择与逐轨标注由谁完成 | 森林的早晨；内容人员确认名称、描述、来源授权与听感 |

| 会话检查 | 被踢发现时机 | 启动、恢复联网及在线播放每 60 秒检查，网络超时不踢出 |
| 下载撤销 | 已发地址的后续使用 | 下载和续传请求仍校验当前有效设备会话 |
| 配置恢复 | 重开 App 行为 | 恢复配置、不自动播放，进程结束后从 A 段起播 |
| 主题切换 | 准备及切换行为 | 新主题就绪前继续旧主题，成功后停旧启新 |
| 下架与撤权 | 已下载主题行为 | 普通下架可继续使用，明确撤权被客户端获知后停止并禁止重开 |
